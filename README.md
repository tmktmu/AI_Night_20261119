# 家計簿アプリ

自分用の家計簿アプリです。ブラウザだけで動き、サーバーやインストールは必要ありません。
仕様は [SPEC.md](SPEC.md) を参照してください。

## 使い方

1. `index.html` をダブルクリックして、Google Chrome で開く
2. **ホーム**：収入・支出を登録します。月ごとの収支と、予算の残りを確認できます
3. **分析**：カテゴリ別の内訳（円グラフ）、予算と実績の比較、月ごとの推移を確認できます
4. **設定**：予算の設定、カテゴリの追加・変更、バックアップと復元ができます

最初に「設定」タブで月の予算を決めておくと、予算に対してどれだけ使ったかが表示されるようになります。

## データについて

- データは、開いているブラウザの中（localStorage）にだけ保存されます
- ブラウザの閲覧履歴やサイトデータを消去すると、記録も消えることがあります
- 「設定」→「バックアップ」で、ときどき JSON ファイルに保存しておいてください。「復元」でそのファイルからデータを戻せます
- 別のブラウザや別の PC で開くと、データは引き継がれません（バックアップファイルを復元すれば移せます）

## テスト

アプリを使うだけなら必要ありません。テストを実行するには Node.js（v22 以上）が必要です。

```
npm install
npm test
```

- `tests/utils.test.js`：金額の表示、日付の計算、入力値のチェック
- `tests/storage.test.js`：データの保存・読み込み、壊れたデータの扱い、バックアップ・復元
- `tests/summary.test.js`：月次サマリー、カテゴリ別内訳、予算と実績、月ごとの推移、1万件での性能
- `tests/ui.test.js`：画面操作（登録・編集・削除、月とタブの切り替え、分析、予算設定、カテゴリ管理、復元）

ブラウザの代わりに jsdom を使い、グラフ（Chart.js）は描画せずに渡された設定を確認しています。

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面 |
| `css/style.css` | 見た目（ライト／ダークモード対応） |
| `js/utils.js` | 金額の表示や日付の計算など、共通の関数 |
| `js/storage.js` | データの保存・読み込み、バックアップ・復元 |
| `js/summary.js` | 集計処理（月次サマリー、カテゴリ別、推移） |
| `js/charts.js` | グラフの描画 |
| `js/transactions.js` | 収支の登録・一覧・編集・削除 |
| `js/budget.js` | 予算設定 |
| `js/categories.js` | カテゴリ管理 |
| `js/app.js` | 起動処理、タブ・月の切り替え、ホームと分析の表示 |
| `lib/chart.umd.min.js` | グラフ用ライブラリ Chart.js 4.4.7 |
